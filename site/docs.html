Rilevamento lingua e traduzione (offline)

Con il modello Whisper multilingua (ggml-small-q5_1.bin) e --lang auto la lingua dell'audio viene rilevata e salvata nei file JSON/SRT. La traduzione di uscita usa due motori locali:

  • whisper (--translate en, engine whisper o auto): ritrascrive con l'opzione -tr di whisper.cpp — nessuna installazione aggiuntiva. Solo verso inglese.
  • argos-translate (--translate it|es|fr|…, engine argos): traduzione neurale offline per coppie arbitrarie (es. en → it). Richiede glibc (sh scripts/setup_argos.sh, param. ARGOS_LANG); a runtime è locale.
# Trucco: film in inglese → doppiato in italiano (voce femminile o maschile)
./stt-tts-ita --lang auto run film.en.mkv -o out \
    --translate it --translate-engine argos \
    --tts-engine piper --tts-voice it_IT-riccardo-x_low
# ... o direttamente sottotitoli SRT/VTT in italiano senza TTS:
./stt-tts-ita --lang auto run film.en.mkv -o out --no-dub --no-tts \
    --translate it --translate-engine argos

Quando --translate è attivo e non specifichi --tts-voice, la voce viene scelta in base alla lingua di destinazione (piper: it → it_IT-serena-medium; espeak: codice lingua).

Dubbing video

  1. Conversione in WAV 16 kHz mono + trascrizione (lingua auto o forzata).
  2. TTS per segmento con synthesize_aligned: parlato nei tempi originali + silenzi nei gap.
  3. Mux con ffmpeg: video -c:v copy (nessuna ricodifica), audio aac 192k, durata invariata (apad + -t).
./stt-tts-ita run video.mp4 -o out --tts-engine piper   # → out/video.dubbed.mp4
./stt-tts-ita run video.mp4 -o out --no-dub              # senza dubbing

Per un video parlato di test (pubblico dominio):

./.venv/bin/python -m pip install yt-dlp
./.venv/bin/python -m yt_dlp -f b "https://commons.wikimedia.org/wiki/File:...webm" -o assets/samples/ita_video.webm

Requisiti a runtime

  • ffmpeg (conversione WAV 16 kHz, concat, mux)
  • espeak-ng (TTS di fallback)
  • modello Whisper in models/; per il bundle dist/debian/ tutto è incluso (Piper + voci)

Build & test

sh scripts/setup.sh                        # dipendenze apt + whisper.cpp + modello
./.venv/bin/python -m unittest discover -s tests -v   # 34 test
sh scripts/build_zipapp.sh                 # dist/stt-tts-ita.pyz (Python ≥ 3.10)
sh scripts/build_binary.sh                 # dist/stt-tts-ita (PyInstaller, glibc del build env)
sh scripts/setup_piper.sh                  # Piper + voci (Debian/glibc)
sh scripts/setup_argos.sh                  # traduttore offline (Debian/glibc)

Portabilità glibc: il binario PyInstaller eredita la libc dell'ambiente di build. Compilato su Debian 11 (glibc 2.31) gira su Debian ≥ 11 e Ubuntu ≥ 20.04; su Alpine/musl si usa lo zipapp con whisper-cli nativo. Percorsi alternativi senza Daemon Docker: rootfs Debian + proot (vedi scripts/debian_rootfs.py).

FAQ

Serve Internet? No a runtime: STT, traduzione (whisper/argos) e TTS sono locali. Internet serve solo all'installazione (modelli Whisper/Piper/argos).

L'audio è più lungo del video? Il dubbing mantiene la durata originale: riempie con silenzio se la lettura è corta e taglia alla durata del video se è lunga.

Quanto pesa? Modello Whisper small ≈ 190 MB; Piper + voci italiane ≈ 250 MB totali.
